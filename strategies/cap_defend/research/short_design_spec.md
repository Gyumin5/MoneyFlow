## 2. 엔진에 숏이 없는 자리 넷 (실측)

연구 엔진은 `unified_backtest.py` 를 복제해 `research/` 아래 둔다. SSoT 는 안 건드린다.
고쳐야 하는 자리는 넷이고, 넷 다 "숏이 안 되는" 게 아니라 "숏이 조용히 틀리는" 자리다.

1. `_get_liq_price` 는 `leverage > 1` 일 때만 불린다(844행). 숏 1배는 청산 판정이
   통째로 빠진다. 방향과 무관하게 항상 평가하고, 숏은 상승 방향(고가)으로 본다.
2. 청산 판정이 저가 기준 하락 방향 전용이다. 숏은 고가 기준 상승 방향이다.
3. 펀딩은 `capital -= holdings × 가격 × 요율`(878행)이다. 수량에 부호를 주면 이 식이
   방향을 그대로 처리한다 — 숏 전용 부호 반전을 덧붙이면 이중 적용이 된다.
4. 흡수(greedy absorption) · 리필 · 드리프트는 롱 헬스를 전제로 돈다. 숏에 그대로
   재사용하지 않는다(아래 5·6절).

손익은 USDT 선물 고정수량이라 방향과 무관하게 선형이다. 숏에서 위험이 가속되는 자리는
손익식이 아니라, 가격 상승과 자본 감소가 동시에 실효 레버리지를 키우고 CROSS 담보를
깎는다는 데 있다.

## 3. 추가 카나리 — 숏 진입 문턱

- `r_t` = BTC 종가 / SMA42
- `s_t` = SMA42_t / SMA42_(t-10) − 1  (이동평균 기울기)
- 롱 허용 상태는 현행 그대로다: `r > 1.015` 에서 켜고 `r < 0.985` 에서 끈다.
- 숏 진입 문턱 `a(x) = min(0.985, 1 − x)`. 진입은 롱 허용이 꺼져 있고 `r < a(x)` 일 때만.
- 숏 청산 문턱 `r >= a(x) + 0.015`.
- 출발 가설: `short_entry_discount = 0.03`, `short_slope_days = 10`, `short_slope_gate = 켜짐`.
  기울기는 진입 때 `s < 0` 만 요구한다. 기울기 조건이 풀리는 것 자체를 청산 신호로 쓰지 않는다.
- 첫 격자의 숏 구성 셋은 한 번에 한 축만 바뀐다:
  - `C0` = (x=0, 기울기 꺼짐) — 기존 오프 구간을 그대로 숏으로 쓰는 진단 대조군. 추천안이 아니다.
  - `C1` = (x=0.03, 기울기 꺼짐) — C0 대비 문턱만.
  - `C2` = (x=0.03, 기울기 켜짐) — C1 대비 기울기만.
- 살아남은 경우에만 인접값 {0.02, 0.03, 0.04} 를 본다.
- 변동성 체제 게이트와 추가 장기 이동평균은 이번 탐색에 넣지 않는다.
- 틀렸을 때의 증상: 진입 직후 최대 역행 증가, 잦은 손절·재진입, 깊은 문턱에서 오히려
  손익 악화, 기울기를 더해도 순위합 개선이 사라짐.

## 4. 숏 헬스와 선정

- 첫 비교 고정값: `short_health_mode = inv_mom2vol`, mom_short 18일 · mom_long 127일 ·
  vol 90일 · vol_threshold 0.05. 통과 조건은 두 모멘텀이 모두 음수이고 변동성이 5% 이하.
  이건 단순 대조 기준이지 "역모멘텀이 옳다" 는 판정이 아니다.
- 변동성 상한은 숏이라는 이유로 다시 열지 않는다. 0.03~0.04 타이트화와 0.06 이상 상향은
  이미 양방향으로 기각됐다(Decisions In Force).
- 선정은 시점별 상위 40 중 헬스 통과분을 시총순으로. 숏에서는 greedy absorption 을 쓰지 않는다.
  후보가 모자라면 빈 몫은 현금이고 다른 종목으로 자동 보충하지 않는다.
- 후속 단일 가설 비교: `short_health_mode = {inv_mom2vol, failed_rally}`.
  `failed_rally` = mom127 < 0 AND 현재 종가 < SMA7 AND 직전 완료 5일봉 중 종가 > SMA7 인 날이
  최소 하나. 변동성 상한은 같다. 반등 실패를 잡는다는 가설이고 우월성은 미확인이다.
- 펀딩은 먼저 비용으로 전액 반영하고 필터는 끈다. 그 다음 `funding_veto = {꺼짐, 켜짐}` 만 비교한다.
  켜짐이면 직전 완료 7일 누적 확정 펀딩을 8시간당으로 환산한 값이 −0.0001 미만인 종목의
  신규 진입·증액을 막는다. 미래 펀딩과 미완성 관측치는 쓰지 않는다.
- 틀렸을 때의 증상: 역모멘텀군의 상방 꼬리손실, 실패 반등군의 과도한 현금화,
  필터가 소수의 큰 수익 종목만 제거.

- 첫 격자 고정: `selection = 5`, `cap = 1/5`. 이후 {(3,1/3), (5,1/5), (7,1/7)} 한 축 비교.

  슬리브 전체 고유 종목 수와 다르다. 스냅 합산 뒤 같은 코인 비중을 합쳐 상한을 다시 적용하고
  초과분은 현금으로 둔다.
- BTC 는 첫 유니버스에 포함. 이후 BTC 포함/제외 비교와 BTC 단독 대조군을 따로 둔다.
  BTC 단독도 숏 명목을 슬리브 자본의 0.20배 이하로 묶고, 바스켓과 위험이 같은 대조군으로
  해석하지 않는다.
- 모든 결과에 실제 고유 보유 수 · 종목별 명목 · 최대 종목 비중 · 명목비중 HHI · 실효 종목 수
  (1/HHI)를 적는다. 명목 종목 수가 는다고 실효 분산이 는다는 보장이 없다.
- 틀렸을 때의 증상: N 을 늘려도 실효 종목 수가 안 늘거나, 상관된 알트가 같이 반등해
  손실과 비용만 커짐.

## 6. 레버리지와 노출

- 출발: `short_leverage = 1`, `short_gross_exposure_cap = 0.75`.
- 총명목 `G = Σ|q_i|·P_i / E`, `E` = 미실현손익 포함 슬리브 순자산.
- 집계 후 종목별 명목 상한 = `E × min(0.20, G_cap/N)`.
- 위험 비교는 `G_cap = {0.50, 0.75, 1.00}` 이고 레버리지 설정은 계속 1배다.
- 거래소 설정 `short_leverage = {1,2}` 비교는 마지막 증거금 정합성 검사로만 둔다.
  같은 명목·같은 수량이면 설정 배수만 바꿔서 수익이 좋아지면 안 된다 — 좋아지면 회계가 틀린 것이다.
- K2·BTC_cap 을 거꾸로 만든 동적 레버리지는 이번 연구에서 제외한다.
- 틀렸을 때의 증상: 설정 배수만으로 청산이 사라짐, 같은 수량인데 손익이 바뀜,
  손실 중 실효 노출 상한 위반이 쌓임.

## 7. 상태 전이와 집행 순서

- 보유 상태는 LONG / CASH / SHORT 하나다.
- LONG → 롱 허용이 꺼지면 다음 시가에 전량 청산.
- SHORT → 숏 청산 문턱 · 롱 허용 켜짐 · 위험 방어 중 하나가 발동하면 전량 청산.
- 반대 방향 진입은 전량 청산 · 미체결 취소 · 잔량 0 확인이 다 끝나고 최소 일봉 하나를
  현금으로 보낸 뒤에만. t 시가에 닫으면 가장 빠른 반대 진입은 t+1 시가이고 t 종가 신호를
  다시 확인한다. 청산이 밀리거나 잔량이 남으면 현금을 더 유지한다.
- 숏 진입 때 스냅 다섯을 초기 선정하고 `short_post_flip_delay = 5` 봉 뒤 한 차례 전체 재평가.
  이후 {0,5} 비교만 허용하고 롱의 5봉 규칙과 기존 스냅 달력은 그대로 둔다.
- `short_rebalance_mode = anchor_fixed_qty` 로 시작한다. 정기 갱신·진입·전환 후 재평가 때
  수량을 정하고, 그 사이에는 헬스 탈락·손절·위험 상한에 따른 축소만 허용한다.
  하락 이익을 보고 매일 숏을 늘리는 리필은 하지 않는다.
- 후속 대조로만 `short_rebalance_mode = target_weight`, `drift_threshold = 0.015` 를 비교하고
  그때는 숏 전용 헬스·선정 경로를 쓴다.
- 라이브는 준비돼 있지 않다. 나중에 별도 승인 단계에서 숏 진입은 reduceOnly 없는 SELL,
  숏 청산은 reduceOnly BUY 로 갈라야 한다. 지금 집행기는 헤지 모드를 스펙 위반으로 중단한다.
- 틀렸을 때의 증상: 반대 방향 잔량 겹침, 롱 재진입 지연, 숏 하락 중 자동 증액,
  정상 음수 포지션을 이상으로 처리.

## 8. 손절과 청산 방어

- 출발: `short_stop_kind = entry_price_pct`, `short_stop_pct = 0.12`.
  진입가 P0 에 대해 S = P0 × 1.12, 1시간봉 고가가 S 이상이면 매수 청산.
- 갭 상승 체결은 `max(그 봉 시가, S)` 에 비용·슬리피지를 더한다. 기존 ±5% 체결 밴드로
  손실을 잘라내지 않는다.
- 후속 비교: 진입가 손절 {0.12, 0.15} → `short_stop_kind = lowest_close_since_entry_pct`,
  `stop_pct = 0.15`. 추적 손절 기준은 직전까지 완료된 일봉의 최저 종가이고 현재 일봉 종가를
  앞서 쓰지 않는다.
- `short_catastrophic_stop_pct = 0.25`, `short_catastrophic_cooldown_bars = 5` 고정.
  일반 손절 뒤에도 그 종목의 숏 재진입을 5일 금지한다. 이 대기는 롱 허용을 막지 않는다.
- `cushion_buffer_mult = 1.5` 로 시작하고 {1.5, 2.0} 후속 비교. 쿠션은 지갑잔액이 아니라
  관측 시점의 미실현손익 포함 순자산 대 유지증거금·청산비용 준비액의 비율로 판단한다.
  임계에 닿으면 신규 주문을 막고 실제 가능한 다음 체결가에서 축소한다.
- 지금 시점에 알 수 없는 시간봉 고가를 보고 그 봉 시가에 미리 축소하지 않는다(룩어헤드).
- 유지증거금률은 공통 비교용 0.004, 스트레스 {0.008, 0.012}. 종목별 실제 티어 자료가 있으면 우선.
- 최소 방어선은 넷의 결합이다 — 낮은 총노출, 종목별 상한, 상승 방향 손절, 계좌 전체 CROSS 정산.
  손절과 1배 설정이 갭 손실을 막아주지 않는다.
- 틀렸을 때의 증상: 1배에서 청산 검사 생략, 개별 배정증거금까지만 손실 반영, 음수 자본 숨김,
  같은 시간봉에서 손절이 청산보다 무조건 먼저 처리됨.

## 9. 비교 구성과 효과 분리

- `A` = 기존 정본 롱 전용 (`backtest_futures_v25.py`)
- `B` = 수정 공통 연구 엔진의 롱 전용
- `C` = 같은 연구 엔진의 롱·숏 상태기계
- `D` = 해당 C 의 롱 진입 허용 일정과 현금 경유 일정을 그대로 쓰되 숏 주문만 뺀 대조군

읽는 법: `B − A` = 엔진 수정 효과, `C − B` = 전략 변경 효과,
`C − D` = 숏을 더한 효과, `D − B` = 방향 전환이 롱에서 뺏은 기회비용.

B 가 A 를 재현 못 하면(설명 못 할 차이가 남으면) 성과 탐색으로 넘어가지 않는다.
자본이 달라져 주문 수량이 달라지는 것은 정상이고, 의도적으로 넣은 현금 대기까지 포함해
롱 체결의 바이트 일치를 요구하지 않는다. 신호·선정·목표비중·스냅 일정은 비교하고 차이를 전부 설명한다.

- 동률이나 "숏 거래가 아예 없었다" 로는 통과시키지 않는다.
- 전체 구간 연복리 순위가 나빠진 후보를 하락 구간 수익으로 구제하지 않는다.
- 문턱 인접값 셋 중 중심값과 적어도 한 인접값에서 개선 방향이 유지돼야 한다. 고립된 최고점은 기각.

## 11. 불확실성 처리

- 441창을 독립 표본으로 재표집하지 않는다(history #97). 후보와 기준선의 일별 수익률을
  달력상 같은 연속 블록으로 짝 재표집한 뒤 같은 창 규칙으로 지표·순위합을 다시 계산한다.
  블록 길이 {126, 252, 504} 일, 각 2,000회. 합산 순위합 차이의 95% 구간 상단이 0 미만인지 본다.
  짧은 블록에서만 유리하거나 긴 블록에서 불명확하면 우월성 미확인으로 남긴다.
- 이 검사도 "독립 하락 사건이 적다" 는 문제를 풀지 못한다. 사건을 고정 카나리 규칙으로
  기계적으로 정의하고 사건별 손익 · 최대 역행 · 펀딩 · 손절 · 전체 개선 기여도를 진단표로 낸다.
  한 사건이 순개선의 절반을 넘으면 사건 집중 경고를 붙이고 일반화 우월성을 주장하지 않는다.
- 사건 제거 재선정 · 홀드아웃 · walk-forward · 연도별 랭크는 쓰지 않는다(프로젝트 규칙).

## 12. 비용과 스트레스

- 거래비용 편도 0.0006 과 5배인 0.003 을 기준선·후보 양쪽에 똑같이 적용한다.
- 최종 생존 후보에만: 손절 매수 체결가의 추가 불리한 슬리피지 {0, 0.01, 0.03},
  높은 유지증거금률, 전 종목 동반 +30% 상승, 단일 종목 +100% 갭.
  뒤 둘은 수익성 평가용이 아니라 방어 동작의 합성 시험이다.
- 비용 5배에서 순위합 개선이 사라지거나 개선이 회전율 증가로 설명되면 기각한다.
  5배 비용과 3% 손절 슬리피지를 같이 적용한 결과도 같이 낸다.
- 어느 실제 역사 경로에서든 계좌 청산 · 파산 · 방향 중첩이 나오면 그 구성은 기각한다.
- 스트레스에서 나온 유리한 결과로 "손절이 손실을 막아준다" 고 주장하지 않는다.

## 13. 측정 순서와 탐색 상한

1. 자료·공통 엔진 검증 → A 재현 (앵커 7회, 사전 비용)
2. 첫 성과 격자 `{B, C0, C1, C2} × 앵커 7곳 = 28회`. 이 단계에서 헬스·종목 수·노출·손절·
   재평가·리밸런싱은 전부 고정한다.
3. 헬스 비교 → 펀딩 필터 → 종목 수·BTC 대조 → 리밸런싱 → 손절·노출·쿠션 → 문턱 인접값
4. 매 단계 직전 기준 구성을 고정하고 한 가설만 바꾼다. 전체 조합의 곱집합은 안 돌린다.

상한: 스트레스 전 고유 구성 최대 24개, 앵커 실행 최대 168회.
첫 격자가 다 실패해도 역모멘텀 가정 하나 때문에 숏 전체를 즉시 기각하지 않는다 —
사전 지정한 C2 의 `failed_rally` 변형과 BTC 단독 변형을 각각 한 번씩만 더 보고,
그것까지 실패하면 "현행 롱 전용 유지" 로 종료한다.

## 14. 이번 결정에 들어 있지 않은 것

라이브 변경, 집행기 수정, 실매매 반영은 이번 결정의 범위 밖이다.
통과하더라도 결과는 후속 검토용 연구 후보이고 라이브 반영은 별도 승인 사항이다.
